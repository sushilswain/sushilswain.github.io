Work / Marketing Intelligence Automation

Marketing operations · CRM reporting

Connecting ad performance to CRM outcomes

I designed a reporting workflow for an admissions team that needs a consistent view of acquisition, lead status and downstream results.

  • Google Ads
  • HubSpot
  • Python and Sheets
  • Higher education

01 · Context

One funnel, several conflicting views

Campaign reports, CRM source fields and admissions records do not automatically tell the same story. Manual exports left the team to reconcile contacts, statuses and deals each time it needed a channel readout.

02 · Strategy

Give each question its own view

Attributed funnel

Assign each contact one primary source so totals are additive and suitable for budget conversations.

Influenced funnel

Preserve overlap among source fields to investigate how channels appear across a contact journey.

Imported contacts

Keep outbound database imports separate from acquired demand.

Exceptions

Flag sales-sheet rows that lack a matching contact or confirming deal.

03 · Execution

Build the reporting path

The Python workflow combines Google Ads data, HubSpot contacts and deals, and admissions records into an Excel report and a matching Google Sheet structure. It includes campaign detail, keyword quality, CRM sections, discrepancies and a weekly channel view. Adaptive date splitting addresses HubSpot search caps; pacing helps respect API limits.

04 · Evidence

A tested reporting design

The July 2026 script passed compile checks and ten targeted synthetic tests covering attribution, discrepancy grouping, weekly filtering and output formatting. The latest changes still need a real-data production run and reconciliation before I describe the report as operating on a recurring live cadence.

05 · Learning

Make business rules visible

Attribution, overlap and unresolved records must be visible alongside a headline channel total. That is what lets a team distinguish a marketing trend from a data reconciliation problem.
