# Sushil Swain — Portfolio V2

Static GitHub Pages site built with HTML, CSS and a small menu script.

## Preview locally

From the repository root, run `python -m http.server 8765`, then open `http://localhost:8765/`.

## Current pages

- `index.html` — homepage
- `projects/appseconnect.html` — paid growth case study
- `projects/search-query-intelligence.html` — governed automation case study
- `projects/marketing-intelligence-automation.html` — ads-to-CRM reporting design
- `projects/ournest.html` — Meta and CRM analysis
- `projects/aarav-infotech.html` and `projects/ajeets-manpower.html` — concise historical work

Shared styles and script live under `assets/`. The APPSeCONNECT charts are under `assets/images/`.
